# Security Policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository, if available. Otherwise, contact the maintainer privately through the address in the repository profile.

Include the affected commit or version, component, impact, reproduction steps, and a minimal proof of concept. Do not include real credentials, private conversations, personal data, or third-party data. You may encrypt sensitive details with a maintainer-provided key.

## Scope and response

The project is maintained on a best-effort basis. There is no guaranteed response time or security support SLA. Please allow time to investigate and prepare a fix before public disclosure.

## Safe testing

Test only systems and accounts you own or are explicitly authorized to assess. Do not upload private files, credentials, or unredacted logs to public issue trackers.
